# Somlance - Production-Grade Freelance Marketplace

Somlance is a high-performance, scalable freelance marketplace platform built for the modern workforce. This monorepo contains the mobile application, admin dashboard, and backend services.

## Project Structure

- `mobile-somlance/`: React Native Expo mobile application.
- `admin/`: React.js administrative dashboard.
- `backend/`: Node.js Express API with Prisma ORM and MySQL.
- `docs/`: Comprehensive engineering and design documentation.

## Getting Started

### Prerequisites

- Node.js (v18+)
- MySQL
- Expo Go (for mobile development)

### Installation

1. Clone the repository.
2. Follow the setup instructions in each subdirectory.

## Engineering Standards

- **Language**: TypeScript throughout the entire stack.
- **Architecture**: Modular, feature-first design.
- **Communication**: REST API (v1) and Real-time via Socket.io.
- **Database**: MySQL with Prisma ORM.
