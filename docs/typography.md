# Typography System

## Font Families
- **Primary**: 'Inter', sans-serif (Clean, modern, highly readable).
- **Secondary**: 'Outfit', sans-serif (Used for headings and brand elements).

## Font Hierarchy
- **H1 (Display)**: 32px / 2rem, SemiBold
- **H2 (Title)**: 24px / 1.5rem, SemiBold
- **H3 (Subhead)**: 20px / 1.25rem, Medium
- **Body Large**: 18px / 1.125rem, Regular
- **Body Regular**: 16px / 1rem, Regular
- **Body Small**: 14px / 0.875rem, Regular
- **Caption**: 12px / 0.75rem, Medium

## Line Heights
- **Headings**: 1.2
- **Body**: 1.5
- **Caption**: 1.4

## Spacing Rules
- Use `tracking-tight` for headings.
- Use `tracking-normal` for body text.

## Responsive Typography
- Mobile: Decrease H1 to 24px, H2 to 20px.
- Desktop: Standard hierarchy.
