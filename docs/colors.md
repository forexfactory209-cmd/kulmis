# Color System

## Primary Colors (Brand)
- **Primary-900**: #0F172A (Deep Navy)
- **Primary-600**: #2563EB (Brand Blue)
- **Primary-500**: #3B82F6 (Action Blue)
- **Primary-100**: #DBEAFE (Soft Blue Tint)

## Secondary Colors
- **Secondary-600**: #7C3AED (Violet)
- **Secondary-500**: #8B5CF6 (Lavender)

## Neutral Colors (Grays)
- **Neutral-900**: #111827 (Black/Text)
- **Neutral-600**: #4B5563 (Secondary Text)
- **Neutral-400**: #9CA3AF (Muted/Placeholders)
- **Neutral-100**: #F3F4F6 (Backgrounds)
- **Neutral-50**: #F9FAFB (Card Backgrounds)

## Success, Warning, Error
- **Success**: #10B981 (Emerald)
- **Warning**: #F59E0B (Amber)
- **Error**: #EF4444 (Red)

## Usage Rules
- **Dark Mode**: Swap `Neutral-50` with `Primary-900` and `Neutral-900` with `Neutral-50`.
- **Primary Action**: Always use `Primary-600`.
- **Borders**: Use `Neutral-200` for light mode and `Primary-800` for dark mode.
